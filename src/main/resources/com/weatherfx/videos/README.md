Optional video backgrounds.

Drop `.mp4` clips in this folder and the app will play them instead of the drawn sky.
Names it looks for:

| Weather                 | File             |
|-------------------------|------------------|
| clear (day)             | `Sunny.mp4`      |
| clear (night)           | `Clear.mp4`      |
| cloudy / overcast       | `Cloudy.mp4`     |
| drizzle, light showers  | `Light_Rain.mp4` |
| moderate / heavy rain   | `Heavy_Rain.mp4` |
| snow, sleet, ice        | `Snow.mp4`       |
| mist / fog              | `Mist.mp4`       |
| thunderstorms           | `Thunder.mp4`    |

Any missing clip just falls back to the animated background. Keep them small
(GitHub won't take files over 100 MB).
